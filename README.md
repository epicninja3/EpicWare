# EpicSquirrelWare
### A WarioWare style game!

Navigate through 3 minigames as a squirrel collecting acorns! But you have a time limit, so go as fast as you can!

## Minigames:
+ Platformer: Jump around onto the platforms to collect acorns
+ Clicker: Click on all the acorns as fast as you can!
+ Asteroids: Dodge the asteroids and collect 5 acorns!

## Controls:
+ Platformer: WASD or Arrow Keys (W/Up Arrow - Jump, A/Left Arrow - Move Left, D/Right Arrow - Move Right)
+ Clicker: Use your mouse and click on each of the acorns
+ Asteroids: Dodge the asteroids using W/Up Arrow to move up and S/Down Arrow to move down
